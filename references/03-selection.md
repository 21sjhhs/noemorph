# 主 Agent 从全部广度候选中选择深度方向

## 两步筛选

1. 整合 `agents × 5` 个原始候选，记录重复/相互包含关系；不可删除原始方向审计记录。
2. 主 Agent 决定进入深度研究的 `top_n`，并输出入选名单、入选理由与未选高潜力方向的保存位置。用户明确指定的 n 优先。

## 评分维度（0–5，各评分是启发式判断）

- `Boundary`: 能否进入原问题未覆盖的概念空间，而不是原学科的常规后续。
- `Depth`: 是否存在可追踪的多级理论、机制、历史、证据或分类路径。
- `Bridge`: 与原问题存在何种可讨论、可检验的实体/现象/结构关联。
- `Evidence`: 是否有明确的独立证据探索路径，而不仅是模型自由联想。
- `Nonredundancy`: 与当轮已选路线的信息差异。
- `Risk`: 远域比附、无证据猜测或已知概念混淆的风险，分数越高越危险。

初始参考分数：

`Score = 0.28*Boundary + 0.25*Depth + 0.22*Bridge + 0.15*Evidence + 0.10*Nonredundancy - 0.15*Risk`

**不以总分机械决定最终名单**。在相关性达到最低阈值后，使用集合级多样性选择，使不同锚点、逻辑操作和未知空间都有机会进入深度。谨防评分偏爱容易搜到的熟悉方向。

## 选题硬约束

- 选出的 n 个方向不能全来自同一拆解节点，除非原问题确实只包含单一独立节点。
- 如果存在合格的去标签化、外域或跨范畴候选，至少保留一个。
- 若某一高分方向与已选路线在语义上重复，则改选有证据前景的互补方向。
- 对非常远的方向，必须写出中介概念或检验路径，避免无约束发散。
- `top_n` 未指定时，根据候选质量与研究预算由主 Agent 自主决定 n，通常 3–8；不是强制每轮选择同一个 n。
- 不允许为了选满数量而接受明显无效的方向；出现不足时如实告知数量和原因。

## 记录

每条入选方向记录 `id`、所属 Agent、来自哪个逻辑节点、为什么优于落选候选、预计深入节点、待核验证据。

未选方向留在 `frontier`，下一大轮可重新考虑。不得将“落选”记录为“错误”。
