# Socrates — 形式逻辑驱动的主词／谓词知识探索

## 不可变原则

- **不预置任何领域内容**：本 Skill 只含抽象符号、逻辑操作和工作规范；从用户当前研究问题中获取所有主题词。不要从此 Skill 衍生出任何特定学科、研究对象或预期答案。
- **五个子 Agent + 一个主 Agent**：主 Agent 负责形式化、委托、选题与最终综合；五个子 Agent 分工固定，详见 `references/02-roles.md`。真实调用才算 Agent；单模型的五种角色扮演不得冒称已执行五个独立 Agent。
- **先定义、后并行**：Agent 1 首先单独解释原问题；Agent 2、3、4、5 随后并行且相互隔离地做广度探索；主 Agent 最后选择 n 条路径调度纵深研究。严禁先生成参考答案再分配探索角色。
- **逻辑是发现问题的语法，不是证明竞赛**：优先寻找未被原问题明确包含、又有解释价值的概念；有限验证必要的跨域关系，不为每条命题开展全面证明。
- **广度必须产生可追踪的新方向；深度必须形成有依据的多级路径**。禁止用近义词数量、引用数量、调用数量、文字长度代替发现深度。
- **盲测隔离**：每次运行默认新目录、不读取历史报告/旧状态/其他对话的研究结论。不得提前向任何子 Agent 传入人类期望它发现的理论名词。

## 用户运行参数

- `question`：研究问题，必填。
- `macro_rounds`：大轮数 `N`，由用户指定；缺失时仅询问轮数。
- `top_n`：每大轮进入深度探索的路径数 `n`；可由用户指定，否则由主 Agent 按有效候选与资源选择，默认目标 4。
- `breadth_per_role=5`：Agent 2–5 **各自恰好提出并调查 5 条语义不同的方向**，共 20 条原始广度方向；Agent 1 **专司原问题的表层释义**，不强行凑五条探索路径。
- `depth_hops=3`：每个入选分支至少**尝试** 3 次连续知识推进；无证据时标注阻塞，禁止编造中间节点。
- **一个大轮**：基于当前锚点由 Agent 1 校准基础解释 → Agent 2–5 广度探索 → 主 Agent 去重并选择 `n` 条 → 深度研究 → 证据审查与状态更新。重复恰好 `N` 次。

## 步骤 0：冷启动与逻辑拆解（主 Agent）

1. 在本次问题中识别问题算子、完整待解释概念、复合成分、修饰限定与隐含论元。
2. 从概念中抽取**主词候选 `S`、谓词/过程候选 `P`、关系 `R`、条件 `C`**；对没有直接主谓形式的问题，先构建**候选语义结构**，不要为了凑 `S—P` 而误判语法。
3. 同时保留整个概念 `X`、拆解出的 `S/P` 及歧义版本；标记哪些来自原问题、哪些是模型假设。
4. 以**带类型的一阶谓词逻辑**记录必要结构；建立待搜索的逻辑查询，不把“可能存在”误当成“已经存在”。详见 `references/01-logic.md`。
5. 仅把**中立的原始问题、最小语义结构和类型/歧义标记**交给 Agent 1。

## 每一大轮的执行顺序

### A. Agent 1：原问题最表层的释义（先执行）

独立回答用户的原始问题，明确基本定义、指称范围、直接必要的术语和主要歧义；避免抢先列举跨域研究方向或冗长的理论目录。其输出必须是**可修订的工作性解释**，不是后续 Agent 不准反驳的公理。主 Agent 合并其解释与初始逻辑拆解，产出紧凑的**共享锚点卡片**。

### B. Agent 2–5：四路独立广度探索（同时执行）

读取 `references/02-roles.md` 与 `references/03-breadth.md`。

- **Agent 2 · 谓词拓展**：固定或明确标注对 `S` 的变化；寻找与 `P` 并列、相邻或机制/结果相关但不必等价的其他谓词／过程 `P′`。
- **Agent 3 · 主词替换**：固定 `P` 的定义与条件，寻找不同于 `S`、能够参与 `P` 或满足其机制前提的其他主词类别 `S′`。
- **Agent 4 · 谓词抽象**：将 `P` 上升到更一般的过程/关系范畴 `G_P`，研究上位分类、相邻下位类别及抽象模型；严格区分**上位概念**和**近义替换**。
- **Agent 5 · 主词抽象**：将 `S` 上升到有证据支持的上位类别 `G_S`，调查针对该上位类别的通用理论、性质和适用边界，再考察回到 `S—P` 的联系。

每个 Agent 独立生成并**至少进行一次实际资料调查**的 5 条不同方向，**只接收相同的共享锚点卡片、当前待探索前沿与其自身角色说明**。在广度结果全部提交前，互相不得看到对方新发现的概念与研究结论。每条方向记录假设、发现、可继续提问的下一跳及证据状态。

### C. 主 Agent：选出 n 个方向

在四组共 20 条**原始方向**全部返回后，先去重、合并等价项，不因合并抹除原始出处。依据**知识边界突破潜力、理论纵深潜力、与原问题的桥接可解释性、证据可得性、组合多样性**评估；详见 `references/04-selection.md`。

- `n` 由用户指定时，不得擅自减少；若有效独立候选不足，明确说明缺口，不得以重复问题填充。
- `n` 未指定时，主 Agent 默认以 4 为目标，按候选质量与可用资源调整并说明原因。
- 若 `n>=4` 且每个探索角色均有合格方向，优先每种角色至少选 1 条；**不能为满足配额强选无价值方向**。
- 优先考虑候选之间能够形成进一步桥接的组合，而非清一色最容易搜索的熟悉问题。

### D. 深度阶段（选题后执行）

读 `references/05-depth-and-evidence.md`。将所选的 `n` 条探索路径分配给**实际可调度的子 Agent**进行连续研究；可复用 Agent 1–5，但应清楚区分阶段与委托，必要时使用分批并行。每条路径至少尝试 3 级推进：每级必须揭示新信息、注明前提和证据，并解释其如何连接到原始问题或中间节点。

- 深度委托不能只要求“再详细解释一遍”；必须追求新概念、新分类、新理论、新方法、不同术语体系或**分支间连接**。
- 如果路径无法证实，标记 `UNVERIFIED`、`BLOCKED` 或 `REJECTED`，不得制造三层貌似完整的证据链。
- 对重要连接区分**同义/包含/共同属性/共有机制/理论可迁移/数学同构/类比/证据冲突**；不得把类比升级为严格等价。

### E. 更新下一大轮研究前沿

- 保留：基础定义的修订、原始 20 条方向、最终入选路径、多级发现、未解决问题、证据、被放弃分支与原因。
- 下一大轮先让 Agent 1 简短校准**原问题定义与新发现有无冲突**；Agent 2–5 从**新前沿的主词/谓词结构**进行下一轮逻辑拓展，不能机械重复上一轮相同的问题。
- 一直保留对用户**原问题**的可追溯关系；必要时向上抽象再返回原问题。不要让上一轮最热门的研究领域成为唯一的新起点。
- 直到完成用户指定的 `N` 个大轮；不得未经要求续跑或在中途强行结束已约定的大轮。

## 最终交付

按 `references/06-report.md` 输出：**先给原问题的修订定义，再给形式逻辑拆解、每大轮四路五方向原始探索、主 Agent 的选题依据、n 条三跳以上深度路径、跨分支联系、独立证据与仍未覆盖的空间**。明确展示什么是真正的新知识，什么只是改名/类比/尚未验证。

## 可执行性与工具边界

- 必须核实当前环境是否具备**真正的子 Agent 委派**。没有该能力时，不得声称五个子 Agent 已运行；说明限制并提供待执行任务包，是否以顺序降级执行由用户决定。
- 工具允许时应做独立的外部证据检索。不能访问外部资料时，报告仅可标记为待证实，不能伪造引用。
- 主 Agent 独占状态文件写入权限，子 Agent 只提交各自结果。`scripts/validate_run.py`（规范见 `references/07-state.md`）只能检查结构与计数，不能证明确实调用过独立 Agent，也不能证明任何科学结论正确。


## 可视化交付扩展（保留原研究骨架）

研究成果与既有报告完成后，按 `references/09-visualization.md` 追加可离线打开的交互知识图谱 HTML 和完整图谱 JSON。使用 `scripts/knowledge_map.py` 读取本轮已有输出，保留全部广度方向、深度路径、原始 ID、资料入口与证据状态；默认突出主要发现，其他分支按需展开。此扩展只负责输出呈现，不改变前述研究流程，也不额外发起研究。`plugins/knowledge-map/` 是配套静态 HTML 可视化插件；`examples/` 仅用于界面演示，不得进入真实研究的冷启动或子 Agent 上下文。

## 启动选择卡与内容语言扩展

用户要求一次新的研究时，在步骤 0 之前按 `references/10-run-configuration.md` 提供跨宿主参数选择卡，收集轮数、并行子代理上限、深入路径数、深度尝试次数和最终呈现语言，保存本次 `run-config.json`。已由用户明确给出的参数直接沿用。五个逻辑角色、隔离和研究阶段保持不变，子代理数量配置解释为并发上限；不得把它直接当成状态脚本的广度提交者数量。维护项目或查看旧成果时不启动这张研究卡。

最终呈现语言不限制任何研究 Agent 的思考或检索语言。原始图谱完成并冻结后，按 `references/11-language-variants.md` 为缺失的目标语言实际调度独立翻译子 Agent，生成声明 `meta.language` 并绑定原图指纹的完整 JSON 副本，再打包进 HTML。界面中英切换与图谱内容语言独立；不得伪装不存在的翻译版本。此翻译阶段是输出处理，不构成新的研究轮次。
