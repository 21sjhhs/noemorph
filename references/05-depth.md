# 深度阶段：从方向到多跳知识路径

## 研究目的

对主 Agent 选择的每个方向进行**纵向递进**的研究，而非把广度问题回答成短段落。强调发现的中间结构、生成新问题的能力与跨分支桥接。

## 至少尝试三层深入

深度任务应依据研究事实动态推进，每条路径至少尝试三种连续研究动作：

1. **定位**：发现可信的对象/理论/概念，查明它在其他研究体系中的实际含义和来源。
2. **结构追溯**：探索其上位理论、前提、构成机制、推导结构、测量方式或历史谱系。不能用同义词重述第一层。
3. **再映射与继续外推**：将上一层发现连接到更一般或更陌生的研究体系，或与另一个已发现分支形成可靠联系，同时明确哪些假设限制迁移。

如研究需要，继续至四、五层；如果某层证据断裂，记录断点及下一步可执行检索，而不是捏造。

## 问题驱动而非清单驱动

对每层的新概念，优先提出：

- 这个知识来自哪个更一般的理论/对象分类？
- 哪个关键假设决定它能否迁移至当前问题？
- 若暂时抹掉当前术语，还有哪些异名知识空间？
- 它与其他新路径有没有共享的结构，是否只是相似而非等价？
- 是否存在更深一层的解释框架，而不是只换一种说法？
- 哪条原始问题隐含的边界因此被突破或推翻？

避免在每一级围绕定义做全套必要性/充分性检验；只对关键桥接和高风险断言做针对性审查。

## 每条路径交付

- `direction_id` 与执行 Agent。
- `hops`：每层的 `question`、`finding`、`why_next`、`relation`、`evidence_refs`、`status`。
- `new_concepts`：新发现概念与其领域、定义、证据。
- `bridges`：知识链连接，标注精确关系类型。
- `boundary_change`：与初始问题相比扩展了哪个认知边界。
- `limits`：理论与方法的适用限制。
- `unresolved`：深度追踪中的断点以及下一步路径。

不得把仅由模型编造的多个层次算作三次真实知识发现；可以完整报告三次**尝试**，即使其中某一次失败。
