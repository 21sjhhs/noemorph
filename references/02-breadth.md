# 广度阶段：独立强制五向探索

## 核心协议

广度阶段以子 Agent 为工作单位。每名实际子 Agent **必须独立提交恰好 5 个不同方向**；方向是能产生独立检索轨迹的研究问题，不能只是相近关键词、同义改写或已知事实的重新表述。

在每个大轮开始，主 Agent 发送：

1. 用户原问题、当前形式拆解结果及概念节点 ID。
2. 本 Agent 负责覆盖的一个或多个锚点；同时保留整体复合概念作比较。
3. 当前已知知识边界和待解决空白（仅限前轮已独立发现的事实；不发送其他 Agent 当轮尚未完成的结果）。
4. 专属的**元认知探索风格**，而不是固定学科角色。
5. 按本协议输出 5 个方向，明确每条的独特性。

## 独立探索策略的五种角色

由主 Agent 给实际 Agent 指派互补的**方法角色**，不是领域角色；多于或少于五个 Agent 时灵活轮换这些方法。

- `Ontology`: 对象类别、上下位、构成—整体、同一与相似性区分。
- `Transformation`: 形成/变化/维持、条件置换、过程—结果的分离。
- `Relation`: 功能、相互作用、替代对象、条件依赖、不同尺度关系。
- `Representation`: 术语、图式、形式理论、观测与解释的对应。
- `Outsider`: 通过去标签化的抽象表述寻找完全不同研究传统的关联。

每个 Agent 应以专属角色为优势，但也要覆盖**多种逻辑算子和拆解节点**；不能重复输出五个相同类型问题。如果拆解包含两个及以上重要构件，每名 Agent 的五个方向至少覆盖两个构件或一个构件加复合整体。

## 方向质量约束

每个方向包含：

- `question`: 可实际研究的开放问题；不包含暗示答案的具体理论名。
- `anchor_ids`: 对应的拆解节点或本轮前沿节点。
- `logical_move`: 该问题依据的形式逻辑/本体操作。
- `discovery_target`: 想寻找的未知对象类别、关系、理论层级或术语空间，不能直接填写猜测出的标准答案。
- `search_route`: 可重复的检索策略；优先从抽象属性、过程或观测模式建立检索，而不是照搬用户题目原词。
- `bridge_test`: 未来如找到远域成果，如何判断其与原问题存在有效联系。
- `novelty_reason`: 相比当前已知边界有何真正不同。
- `unknowns`: 预期无法直接断定的事。

生成后自检：

- 五条方向是否独立？是否有两个以上不同逻辑操作？
- 是否覆盖原问题复合概念和若干组件，而不是只沿最熟悉的一项扩展？
- 是否至少尝试一条完全去术语锚定的外域路径？
- 是否避免提前把猜测的答案放入问题？
- 是否有能够判断有效关联的桥接条件？

如果一名 Agent 给出少于 5 条有效方向，主 Agent 必须要求**该名真实 Agent**补足，或重新委派同等独立研究任务；不得自行替它编造方向。

## 广度成果与证据

广度的主要产物是**方向与潜在入口**，允许标记未经验证。研究 Agent 可以提供探索性搜寻所得的概念，但不应花费多数预算编制长篇学术综述或逐命题证明。它应提供足够证据线索，支持主 Agent 在下一阶段做方向选择。

五个方向不代表已经产生五项研究发现；方向必须与结果分开计数。
